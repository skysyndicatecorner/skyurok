# Как помочь проекту

SkyUrok распространяется под лицензией GNU AGPL-3.0 или более поздней версии. Отправляя изменения, вы соглашаетесь, что они выходят под той же лицензией.

- **Нашли ошибку или не хватает функции** — создайте Issue по шаблону.
- **Перенос из другой программы сработал не полностью** — опишите, чего не хватило. Файл прикладывайте только без персональных данных.
- **Код** — Pull Request в ветку `main`. Перед отправкой:

```sh
cargo fmt --all
cargo test --workspace --release
cargo clippy --workspace
```

Тексты интерфейса — на русском, короткие и конкретные: что произошло и что делать дальше.
