# Формат файлов .rtt — заметки разработчика

Файлы .rtt создают некоторые другие программы составления расписания.
SkyUrok умеет переносить из них часть данных, чтобы школе не вводить всё заново.

Разобрано по образцам файлов данных, без использования кода других программ. Всё little-endian, строки — Delphi ShortString
(1 байт длины + символы cp1251) в поле фиксированной ширины; остаток поля —
мусор из памяти, его игнорируем.

Файл = последовательность секций: ASCII-метка `[Имя]`, сразу за ней тело.
Тело большинства секций начинается с `u32` — числа записей.

| Секция | Запись | Поля | Статус |
|---|---|---|---|
| General | — | i32[29]: версия формата (7), 22, 1, 5, 6/7, затем веса штрафов (10000 — нерасставленный урок, 50 — прочие), 32767/10, 500, 100, −1… | частично |
| Class | 88 байт + хвост 8–13 | id i32 · имя string[11] (12 б) · смена · учеников · мин уроков · макс уроков (i32×4) · график 56 б · хвост (u32 + переменная часть) | основные поля читаются; начало следующей записи ищется по сигнатуре |
| Teacher | переменная | id · i32 (−1?) · фамилия string · поля «-» · график 2×28 б (бит на день?) · имя-отчество string[≈40] · … | не разобрано |
| Replacement | — | u32 число замен | пусто в изученных образцах |
| Subject | 72 | id · имя string[15] (16 б) · трудность i32×11 (годы обучения 1–11) · короткое string[3] (4 б) · область i32 | читается |
| Area | 28 | id · имя string[23] | читается |
| Room | 36 | id · имя string[15] · мест i32 · 12 байт (вероятно, корпус и флаги; первые 4 б иногда похожи на мусор-указатель) | читается, корпус — нет |
| Load | переменная | нагрузки, группы, учителя | не разобрано |
| Plan | переменная | учебный план | не разобрано |
| Schedule | переменная | сетка расписания | не разобрано |
| PeriodTimes | переменная | привязка к датам учебного периода | не разобрано |
| Section_EgeSchool | — | встречается не во всех файлах (профильные группы?) | не разобрано |

## Недельный график (гипотеза)

56 байт = 2 недели (чёт/нечёт) × 28 байт. Байт = урок (до 28), биты = дни недели.
Встречаются значения 0xC0 (доступен), 0xFE (недоступен), у учителей 0x90/0x94/0xBE.
Вероятно, бит 1 = день недоступен, бит0/бит7 — служебные. Требует сверки:
нужны образцы с известными настройками класса и учителя.

## Вариант формата с понедельным расписанием

Другой формат: `[General]` короче, далее `[Section_Area]` и т.д. Отдельный импортёр.

## Альтернатива

Некоторые программы выгружают XML для электронных журналов — образец
такого файла позволит перенести учителей и нагрузки быстрее, чем разбор Load/Teacher.

## Как помочь

Сохраните в исходной программе цепочку маленьких файлов, каждый на одно изменение
больше предыдущего: пустая школа → + один учитель → + одна нагрузка → + один урок
в сетке. По разнице между файлами расшифровываются оставшиеся секции.
