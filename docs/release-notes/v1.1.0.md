SkyUrok 1.1 — версия доверия: школа может перейти и ничего не потерять.

## Какой файл скачать

| Система | Файл |
|---|---|
| Windows 10 и 11 | `SkyUrok-windows-x64.zip` — распаковать и запустить `SkyUrok.exe` |
| Debian, Ubuntu, Astra Linux | `skyurok_1.1.0-1_amd64.deb` |
| РЕД ОС, Альт, Fedora | `skyurok-1.1.0-1.x86_64.rpm` |
| Любой Linux с glibc 2.28+ | `SkyUrok-linux-x86_64.tar.gz` → `./install.sh` |
| Android 7+ (предварительная) | `SkyUrok-android.apk` |

Контрольные суммы — в `SHA256SUMS.txt`. Результаты замера генератора — в отчёте сборки на вкладке Actions.

## Главное

- **Замены переживают пересоставление.** После «Составить» назначенные замены находят свои уроки; если урок переехал, замена помечается «пересмотреть». В 1.0 они терялись.
- **Версии расписания** — сохранить под своим именем и вернуть; перед каждым составлением текущее сохраняется само.
- **Замок файла и резервные копии** — предупреждение, если проект открыт на другом компьютере, и 30 последних копий.
- **Страница замен для телефона** и QR-код на листе замен. Причины отсутствия на листе по умолчанию не печатаются.
- **Нагрузки из Excel** по шаблону; баллы трудности — таблицей, к новым санитарным нормам 2027 года.
- **Генератор стал заметно точнее.** В 1.0 кнопка «Составить» из-за ошибки не доводила расчёт до конца: оценка демо-школы была 2525, теперь 83 (меньше — лучше).
- **Генератор на всех ядрах** и подсказка, если часы не помещаются в принципе (например, не хватает спортзала).
- **Подписи ячеек сетки** для программ экранного доступа.

## Важно при обновлении

Файлы проекта 1.0 открываются и переводятся сами. Версия 1.0 файлы, сохранённые в 1.1, не откроет — обновите программу на всех компьютерах школы.

## Известные ограничения

- Нет чередования чётной и нечётной недель и учёта смен — запланировано в 1.2.
- Из .rtt переносятся только классы, кабинеты и предметы.
- Подписи для экранного доступа ещё не проверены с NVDA на Windows.
- Android-версия повторяет интерфейс компьютера: удобна на планшете.
- Windows покажет предупреждение о неизвестном издателе: у сборки нет платной подписи.

Полный список изменений — в `CHANGELOG.md`.
