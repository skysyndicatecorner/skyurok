Первый стабильный выпуск SkyUrok — программы для составления школьного расписания и замен.

## Какой файл скачать

| Система | Файл |
|---|---|
| Windows 10 и 11 | `SkyUrok-windows-x64.zip` — распаковать и запустить `SkyUrok.exe` |
| Debian, Ubuntu, Astra Linux | `skyurok_1.0.0-1_amd64.deb` |
| РЕД ОС, Альт, Fedora | `skyurok-1.0.0-1.x86_64.rpm` |
| Любой Linux с glibc 2.28+ | `SkyUrok-linux-x86_64.tar.gz` → `./install.sh` |
| Android 7+ (предварительная) | `SkyUrok-android.apk` |

Контрольные суммы — в `SHA256SUMS.txt`.

## Главное

- Составление расписания в фоне со сравнением «было / стало», несколько зданий, группы и потоки.
- Замены с объяснением каждого варианта, автоподбор на день и неделю, отсутствие класса.
- Печать в Word и PDF без Office. При ошибках в расписании — выгрузка с пометкой «Черновик».
- Светлая и тёмная темы, масштаб до 200%, поддержка программ экранного доступа, обучение и поиск по Ctrl+K.
- Перенос классов, кабинетов и предметов из файлов .rtt других программ.

## Известные ограничения

- Нет чередования чётной и нечётной недель и учёта смен — запланировано в 1.2.
- Из .rtt пока не переносятся учителя, нагрузки и готовое расписание.
- Android-версия повторяет интерфейс компьютера: удобна на планшете, на телефоне тесно.
- Windows покажет предупреждение о неизвестном издателе: у сборки нет платной подписи.

## Лицензия

SkyUrok — свободная программа под GNU AGPL-3.0 или более поздней версией. Пользоваться можно без ограничений; изменённые версии, в том числе работающие как онлайн-сервис, должны оставаться открытыми под той же лицензией.

Полный список изменений — в `CHANGELOG.md`.
